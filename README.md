# '공제조합' 매각·경매·공매 카톡 알림

**평일(월~금) 18:00**(한국시간)에 아래 3곳을 확인해서 `공제조합`이 들어간 건을 카카오톡 "나와의 채팅"으로 보냅니다.
없으면 "해당 없음" 결과를 보냅니다. GitHub Actions에서 돌아가므로 PC를 켜둘 필요가 없습니다.

| 대상 | 검사 범위 | 새 건 판별 |
|---|---|---|
| 대법원 회생·파산 자산매각 공고 | 제목·매각기관·본문·**첨부파일**(PDF/HWP/HWPX/DOCX/XLSX/ZIP) | 직전 실행 이후 올라온 글 |
| 법원경매정보 부동산 매각공고 | 사건번호·용도·소재지·**비고** 등 공고 상세 전체 — **최초 입찰 제외, 2회차(유찰 1회 이상)부터** | 처음 보는 매각공고(이번 달·다음 달, 전국) |
| 온비드(자산관리공사) 공매 | 부동산·동산 물건목록의 물건명·용도·기관 등 전체 항목 | 아직 알리지 않은 물건 |

## 1단계. 카카오 개발자 앱 만들기 (10분)

알림 받을 카카오 계정(010-8954-3531)으로 진행합니다.

1. https://developers.kakao.com → 로그인 → **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름: 공제조합알림)
2. **앱 키**에서 `REST API 키` 복사해 두기
3. **카카오 로그인** → 활성화 **ON** → **Redirect URI** 에 `https://localhost` 등록
4. **카카오 로그인 → 동의항목** → `카카오톡 메시지 전송(talk_message)` → **선택 동의**
5. **플랫폼 → Web → 사이트 도메인**에 아래 3개 등록 (카톡 링크 버튼이 열리려면 필수)
   - `https://www.scourt.go.kr`
   - `https://www.courtauction.go.kr`
   - `https://www.onbid.co.kr`
6. (선택) **보안 → Client Secret** 을 켰다면 그 값도 복사

## 2단계. 카카오 리프레시 토큰 받기 (내 PC에서 1회)

```
pip install requests
python kakao_setup.py
```
- REST API 키 입력 → 나오는 주소를 브라우저에 붙여넣기 → 로그인·동의
- "사이트에 연결할 수 없음" 화면이 떠도 정상 → **주소창 전체** 복사해서 붙여넣기
- 카톡 "나와의 채팅"에 테스트 메시지가 오면 성공. 화면에 나온 **REFRESH TOKEN** 복사

## 3단계. 온비드 OpenAPI 키 받기 (무료, 5분)

1. https://www.data.go.kr 로그인
2. 아래 2개를 검색해서 각각 **활용신청** (개발계정은 보통 즉시 승인)
   - `한국자산관리공사_차세대 온비드 부동산 물건목록 조회서비스`
   - `한국자산관리공사_차세대 온비드 동산 물건목록 조회서비스`
3. 마이페이지 → 개발계정 → **일반 인증키(Decoding)** 복사 → `DATA_GO_KR_KEY` 로 사용
4. **동산 물건목록**의 상세 화면에서 요청주소를 확인하세요.
   `https://apis.data.go.kr/B010003` 뒤에 붙는 부분(예: `/OnbidXXXXSrvc2/getXXXX2`)을
   GitHub **Variables** 의 `ONBID_MOVABLE_PATH` 에 넣습니다. (부동산은 코드에 이미 들어 있음)

## 4단계. GitHub 저장소 설정

1. **Private 저장소**에 이 폴더 파일 전부 업로드 (`.github/workflows/daily.yml` 구조 유지)
2. **Settings → Secrets and variables → Actions**

**Secrets** 탭

| 이름 | 값 |
|---|---|
| `KAKAO_REST_API_KEY` | 1단계 REST API 키 |
| `KAKAO_REFRESH_TOKEN` | 2단계 리프레시 토큰 |
| `KAKAO_CLIENT_SECRET` | (Client Secret 켠 경우만) |
| `DATA_GO_KR_KEY` | 3단계 일반 인증키(Decoding) |
| `GH_PAT` | (권장) 아래 참고 |

**Variables** 탭

| 이름 | 값 |
|---|---|
| `ONBID_MOVABLE_PATH` | 3단계 4번의 동산 물건목록 요청주소 뒷부분 |

3. **Settings → Actions → General → Workflow permissions** → `Read and write permissions` 저장

### GH_PAT (카카오 토큰 자동 연장용, 권장)
카카오 리프레시 토큰은 **2개월** 유효합니다. `GH_PAT`을 넣어두면 만료 1개월 전에 자동으로 교체합니다.
- GitHub 프로필 → Settings → Developer settings → **Fine-grained tokens** → Generate
- Repository access: 이 저장소만 / Permissions: **Secrets → Read and write** / 만료일 최대
- 넣지 않으면 2개월마다 2단계를 다시 해서 `KAKAO_REFRESH_TOKEN`을 교체해야 합니다.

## 5단계. 테스트

**Actions** 탭 → `공제조합 감시 (회생파산·법원경매·온비드)` → **Run workflow**
- `test-kakao` : 카톡 연결만 확인
- `dry` : 카톡 없이 결과를 로그로만 확인 ← **처음엔 이걸로 3곳 모두 정상 조회되는지 확인**
- `run` : 실제 실행 (이후 평일 18시 자동)

## 참고
- 주말에 올라온 공고는 월요일 실행 때 함께 확인됩니다.
- **법원경매 회차 판단**: 유찰횟수 항목이 있으면 그 값으로, 없으면 `최저매각가 < 감정가`면 2회차 이상으로 봅니다. 판단할 수 없는 건은 놓치지 않도록 알림에 포함합니다. 1회차부터 받으려면 `daily.yml`의 `AUCTION_MIN_ROUND`를 `"1"`로 바꾸세요.
- 검색어 추가: `daily.yml`의 `KEYWORDS: 공제조합` → `KEYWORDS: 공제조합,출자증권` 처럼 쉼표로.
- 특정 사이트 끄기: `daily.yml`의 `SOURCES`에서 빼면 됩니다 (`scourt`, `court_auction`, `onbid`).
- **법원경매**: 사이트가 호출이 많으면 접속을 1시간가량 차단하므로 2~3초 간격으로 조회하고, 1회 상세 조회는 60건까지만 합니다(남은 건 다음 날). 차단되면 결과 메시지에 표시됩니다.
- **법원경매 링크**: 법원경매정보는 공고별 고정 주소가 없어 매각공고 화면으로 연결됩니다. 메시지의 법원·사건번호로 검색하세요.
- **온비드 링크**: 온비드 첫 화면으로 연결됩니다. 메시지의 물건관리번호로 검색하세요.
- 온비드 개발계정은 API별 하루 1,000회 제한이 있으며, 1회 실행에 약 100회 사용합니다.
- 스캔(이미지) PDF 첨부는 글자를 읽을 수 없어 "글자 인식 불가 N건"으로 표시됩니다.
- GitHub 예약 실행은 **수 분~수십 분 늦게** 시작될 수 있습니다.
- 실행이 실패하면 GitHub에서 메일이 오고, 가능하면 카톡으로도 오류 알림이 갑니다.
